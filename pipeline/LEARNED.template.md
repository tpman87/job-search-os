# Learned — corrections you've given this tool, in your own words
<!-- Copy to LEARNED.md (gitignored). See .claude/skills/retrospective/SKILL.md. -->

Every time you correct a verdict, a piece of writing, or a scoring decision this tool
made, that correction gets written here — dated, with the reason. A correction made once
and never recorded gets made again in three weeks, because nothing carries it forward. A
correction written here is read by every skill in this repo before it acts, so it only
needs to be said once.

**Why this file exists specifically, rather than trusting memory:** the tool this repo was
built from kept its equivalent corrections scattered across half a dozen files, and by the
time anyone tried to hand the method to someone else, it was navigable only by the person
who'd lived through every correction. One file, one habit, prevents that.
