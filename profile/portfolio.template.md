## ⚠️ Read this before filling in the first project

Cover letters need a **friction moment** — something that went wrong, and what changed
because of it. Under drafting pressure, a system with no real documented failure on file
will *invent* one, because a small, surprising, mildly self-deprecating detail is exactly
what the moment calls for — and an invented one reads as authentic precisely because it's
specific. That's the single most common and most dangerous failure mode this tool guards
against. The guard is structural: **every project below needs a real documented failure,
or the writing skills will not use it for the friction beat.**

"Documented" doesn't mean written down somewhere formal. It means you can answer three
follow-ups without inventing anything:
1. **What specifically changed?** (Not "it got better" — what did you actually do differently.)
2. **Who noticed, or what evidence shows the before/after?** (A number, a person's reaction,
   a decision that got made because of it.)
3. **What would you cite if someone asked "how do you know"?**

If you can't answer all three for a project, **don't force a failure story for it.** Leave
the field UNKNOWN and use a different project for the friction beat, or tell the letter's
story without one. A missing failure is fine. An invented one is the thing this system
exists to prevent.
